## Context

`.agents/` is the one source for every agent tool: `instructions/` (each area's `AGENTS.md` + `CLAUDE.md`), `config/*.json` (hooks, permissions, MCPs, plugins, sources), `commands/`, `skills/`, `setup.sh`. `clis/agent-config-sync` renders them into real files (no symlinks) in Claude Code, Codex and opencode's native locations.

## Guidance

- Edit only `.agents/` sources, then run `pnpm run sync:agent-config`.
- Generated files carry a "generated by agent-config-sync" header where the format allows comments. Path-free outputs are committed; ones embedding absolute paths (`opencode.json`, `.mcp.json`, `.codex/*`, `.opencode/hooks.json`) are gitignored.
- `pnpm run sync:check` fails on a drifted, stale or symlinked output.

## Why this matters

Hand edits to generated files are overwritten on the next sync (every SessionStart), and two hand-maintained copies drift: root `CLAUDE.md` and `AGENTS.md` had diverged before they were generated from one source.

## When to apply

- Adding or modifying agent hooks, permissions, plugins, or MCPs.
- Fixing an agent behavior issue that seems to involve a generated file.
- Reviewing a PR that touches agent configuration.

## Examples

```bash
# After editing .agents/config/hooks.json
pnpm run sync:agent-config

# Verify generated files are in sync before committing
pnpm run sync:check
```
