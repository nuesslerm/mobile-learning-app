Coverage and reproduction

wf test run --performance starts real serve, RCA service and executor processes on loopback. The harness pairs each client, prepares a temporary repository or chat, times the repeated operations and checks the answers. Setup, compilation, UI rendering and live model inference are outside the reported journey durations.

wf --performance rca bearers list was separately tested against a loopback HTTP fixture. SQLite recorded the command, the RCA route and its HTTP GET, including the HTTP call site. A flow test exercised missing samples, a deliberately slow span, repeated SQLite imports and command exit codes.

OTLP parent IDs describe nesting within each instrumented process. The run ID groups all processes. Third-party subprocess boundaries give elapsed invocation time. Internal requests require telemetry from that subprocess.
