# Sidebar profile on rca

On the rca iPhone 18 Pro Max running iOS 27, Expo Go shows the circular profile button in the lower left of the Learning workspace drawer in light appearance. Tapping it opens account Settings, where Profile is the first row. The coding-agent shortcut remains on the right. [Drawer](drawer.png) · [Account Settings](account.png) · [Recording](expo.mp4)

Open the Tamil Library on the [verified EAS update](https://expo.dev/accounts/nuesslerm/projects/mla-tamagui/updates/65315bb0-90e3-4d61-b9ac-e978bbdef958) and run [the native runbook](verify.lua) with an absolute screenshot directory in `out`. The restored control was introduced in the [default-route cutover](https://github.com/nuesslerm/mobile-learning-app/commit/43083505).
