# T3 preview operations

Mimic recorded the packaged T3 0.1.9 server on loopback. A synthetic RPC client paired with a disposable project and opened server and desktop preview tabs, listed them, resized them to a 390 by 680 freeform viewport and closed them. The JSON contains the eight observed requests with their correlated responses extracted from the WebSocket interaction. It omits the pairing handshake and fixture project setup. Page frames and input use a separate viewer connection.

The recorder classified the local cassette as authored because the upstream was selected locally without a configured reference pin.
