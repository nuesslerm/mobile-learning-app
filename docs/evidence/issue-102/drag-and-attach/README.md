# Fullscreen and terminal attachments on iOS

The published Expo update was opened on the rca simulator. Dragging moved the control while the streamed terminal stayed fullscreen. Tapping the relocated control exited fullscreen. Tapping Attach image in the streamed Expo terminal opened iOS Photos. Selecting the simulator photo inserted a quoted path. The staged JPEG was 4,122,312 bytes. Cancelling a second selection preserved the draft. The native Expo terminal also opened Photos and staged the selected image.
