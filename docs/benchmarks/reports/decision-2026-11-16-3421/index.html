The cruised-module count is unchanged (549 modules before and after, identical rule set, 0 violations); a planted feature directory was cruised after `wf check --layout --write` (552 modules, its domain-to-ui import failed `domain-imports-nothing`) with no script edit. `wf check --layout` took 0.10 s, the app's oxlint step 2.9 s. `depcruise.feature.cjs` is removed: nothing required it, its only reference was a cache input in `nx.json` that `archRules` (`frontend/feature-kit/**`) already covers.
