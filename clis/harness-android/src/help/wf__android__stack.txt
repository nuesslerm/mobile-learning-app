Usage: wf android stack <group> [--platform P] [--file F] [--update-id ID] [--map PATH]

Maps a logged JavaScript stack to source lines off-device. <group> is the EAS update group in the log or update link.
The default map comes from the group's encrypted GitHub Actions artifact, using gh authentication and CI_DB_KEY
from the vault. WF_EAS_MAPS_DIR reads the same sealed layout locally. For a local build, pass the exact map with --map.
Hermes frames map to name (source:LINE:COL). Unrecognized frames stay as logged and carry mapped: false.

Options:
  --platform <p>        ios or android (default android)
  --file <path>         read the stack from a file instead of stdin
  --update-id <id>      require the sealed map to match the log's platform update ID
  --map <path>          use a local map from the exact build instead of downloading one

Result: {group, platform, map, updateId, frames: [{raw, mapped, source, line, column, name}], text}
