Pair T3 Code

Use a server address and one-time code to add your Mac as an environment. Install T3 Code and connect to Tailscale on this iPhone first.

  1. Create a pairing code

    Have T3 Code ready. The code expires in five minutes.

  2. Add the environment in T3 Code

    Open Settings → Environments → Add environment. Enter the address and code, then tap the checkmark.

  3. Open your Mac environment

    Find Mac · Mobile Learning under Environments and check that it shows Connected.
